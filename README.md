# BTTR for atrial fibrillation in sinus-rhythm ECG (PTB-XL)

Reference pipeline for the paper *"An interpretable tensor model for identifying atrial fibrillation in sinus-rhythm ECG: block-term tensor regression on PTB-XL, benchmarked against deep and foundation models"* (Cornelissen & Faes). It applies **real Block-Term Tensor Regression** (Faes et al., the vendored `bttrlib/`) to PTB-XL and benchmarks it, on age- and sex-matched controls and identical patient-grouped folds, against a clinical-feature logistic regression, an Attia-style 1-D CNN, an unsupervised CP/PARAFAC surrogate, and frozen HuBERT-ECG foundation-model embeddings. BTTR yields directly inspectable (time x lead) weight maps. PTB-XL has no outcome follow-up, so the AF-in-SR task is identification of a sinus-rhythm record followed by an AF record within 31 days, not future-onset prediction.

## BTTR is genuine block-term tensor regression (not a CP surrogate)

`bttrlib/bttr.py` + `bttrlib/ace.py` implement supervised, deflation-based BTTR: a mode-1 cross-covariance tensor between X and the +/-1 label is Tucker-decomposed each iteration; Automatic Component Extraction (ACE) selects each block's multilinear rank by a BIC sweep; a score vector is SVD-extracted and both X and the target are deflated before the next block, for K blocks. With `enforce_rank_1=True` each block is a readable `(time x lead)` weight map. This is structurally distinct from the unsupervised `parafac` CP surrogate in `core/baselines.py` (a separate baseline, not the method). **`bttrlib/` is vendored - never algorithm-edited** (one tensorly>=0.8 compat shim only).

## Layout (this is a package - run drivers from this directory)

- `bttrlib/` - **vendored** real BTTR: `bttr.py` (deflation loop), `ace.py` (automatic rank), imported as a top-level package (`from bttrlib import BTTR`).
- `core/` - shared library: `config.py` (paths + cohort/BTTR/tensorisation settings; **edit `PTBXL_DIR`**), `data.py` (PTB-XL loading), `preprocess.py` (wavelet denoise + tensorisation: `window` / `median_beat` / `median_beat_rr`), `bttr_model.py` (sklearn-style `BTTRClassifier` + `block_maps()`), `baselines.py` (clinical features + CP surrogate), `evaluate.py` (patient-grouped CV + bootstrap CI).
- `experiments/` - the keeper drivers that produce the paper numbers.
- `paper.py` - the single entry point that runs the whole flow.
- `manifests/` - the record-level cohort and split manifests (deposited; regenerated by `paper.py`): `afsr_afib_draws.csv` and `afsr_aflt_draws.csv` list every record of each of the ten matched control draws (seed, ecg_id, patient_id, label, age, sex, recording_date, days_to_af, outer fold), and `cohort_summary.csv` the demographics of the seed-0 draw.
- `results/` - generated CSVs + block-map `.npz`/`.png` + the HuBERT embedding cache `hubert_emb.npz` (regenerated by `paper.py`).

The **algorithm** lives in `bttrlib/` (vendored BTTR) wrapped by `core/bttr_model.py`; the benchmark is driven by `experiments/`.

## Data (public)

PTB-XL 1.0.3 (PhysioNet, DOI 10.13026/x4td-x982), open access (PhysioNet account, no DUA). The whole database is needed: the control pool is every patient without an AF or flutter record (14,899 candidates), and the detection-context step reads 500 Hz records. Download it into `~/data/ptb-xl/` (`ptbxl_database.csv`, `scp_statements.csv`, `records100/`, `records500/`), for example `aws s3 sync --no-sign-request s3://physionet-open/ptb-xl/ ~/data/ptb-xl/` or the zip from https://physionet.org/content/ptb-xl/1.0.3/, or set `PTBXL_DIR` in `core/config.py` to another location. HuBERT-ECG weights (`Edoardo-BS/hubert-ecg-small` on Hugging Face; DOI 10.1101/2024.11.14.24317328) are downloaded by the HuBERT step on first use.

## Cohort

`experiments/harden_afsr.py` builds the cohorts. A positive is a sinus-rhythm (SR) record of a patient with an AFIB record (AFIB or AFLT for the secondary cohort) dated 0 to 31 days after it; every such record counts, so a patient can contribute several (42 records from 37 patients; 55 from 46). Control candidates are patients with no AFIB or AFLT record anywhere, one SR record each (lowest `ecg_id`). `match_controls` gives each positive the 3 nearest-age same-sex unused candidates, in a seeded order with seeded tie-breaking. Seeds 0 to 9 give the ten control draws; each draw is cross-validated with `StratifiedGroupKFold(5, shuffle=True, random_state=seed)` grouped by patient. Seed 0 is the single draw that carries the bootstrap intervals.

## Reproduce

```bash
pip install -r requirements.txt
python paper.py            # runs the full flow (about 1 h on a laptop): manifests/, results/, the manuscript figures and the journal figure files
```
Individual steps run as `python -m experiments.<name>`. The HuBERT step needs `transformers` + `torch` + network (downloads the weights once); the CNN baseline needs `torch`; both are benchmark baselines, not dependencies of BTTR.

## Script -> result -> manuscript map

| Script | Produces | Manuscript element |
|---|---|---|
| `experiments/export_manifests.py` | `manifests/*.csv` | cohort rules, demographics, record identifiers and folds |
| `experiments/hubert_probe.py` | `results/hubert_probe.csv`, `results/hubert_emb.npz` | the HuBERT-ECG embeddings used by every later step |
| `experiments/final_eval.py` | `results/final_table.csv` | seed-0 draw: AUROC point estimates with 95% patient-bootstrap CIs and AUPRC, all five methods |
| `experiments/plot_forest.py` | `results/forest_auroc.png` | preview of the forest figure |
| `experiments/paired_test.py` | `results/paired_test.csv` | Table 2: paired BTTR-minus-baseline differences with 95% paired CIs (two HuBERT probes) |
| `experiments/benchmark_draws.py` | `results/benchmark_draws_r3.csv`, `results/benchmark_draws_r3_scores.npz` | Table 1: all methods and age alone over the ten matched draws |
| `experiments/matched_ablation.py` | `results/matched_ablation.csv`, `results/matched_ablation_scores.npz` | Table 3: BTTR and CNN, aligned and unaligned, under both protocols; the npz holds every draw's out-of-fold scores |
| `experiments/pooled_paired.py` | `results/pooled_paired.csv`, `results/pooled_paired_alignment.csv` | paired 95% CIs of the ten-draw mean differences (one patient resample applied to all ten draws): BTTR minus each baseline, and aligned minus unaligned for BTTR and the CNN |
| `experiments/harden_afsr.py` | `results/harden_afsr.csv` | the tensorisation comparison and the K sweep over the ten draws; also the cohort builder used by the others |
| `experiments/run_analyses.py` | `results/analyses.csv` | map-stability r over the ten draws, and a symmetric inner-CV-tuned check |
| `experiments/interpret_afsr.py` | `results/interpret_afsr_afibonly_blocks.{npz,png}` (+ secondary) | the block-map figure |
| `experiments/weight_fractions.py` | `results/weight_fractions.csv` | the temporal weight fractions (atrial/QRS/ST/T) |
| `experiments/run.py --task detect` | `results/results_detect.csv` | the detection-context numbers |
| `experiments/nested_afsr.py` | `results/nested_afsr.csv` | the nested-CV robustness cross-check |
| `experiments/export_journal_figures.py` | `Fig1.{eps,tif}` and `Fig2.{eps,tif}` in `../admin/submission/figures/` (or `$BTTR_FIGURES_DIR`), plus `forest_auroc.png` and `interpret_afsr_afibonly_blocks.png` in `../manuscript/figures/` (or `$BTTR_MANUSCRIPT_FIGURES_DIR`) | the forest figure and the block-map figure as separate journal files: 174 mm wide, 8 pt Arial, EPS with embedded fonts, 600 dpi RGB TIFF, no suptitle; the two manuscript PNGs are the same drawing at 300 dpi and overwrite the earlier PNGs of those names |
| `experiments/graphical_abstract.py` | `Graphical_Abstract_Cornelissen.{tif,pdf}` in the same folder | the 32.93 x 37.63 mm graphical abstract: one sinus-rhythm trace (needs PTB-XL), the block map with the largest absolute coefficient from the `.npz`, and the ten-draw mean AUROC of BTTR and of the best other method from `benchmark_draws_r3.csv` |

`export_journal_figures.py` and `graphical_abstract.py` read the `results/` files and run after `final_eval.py`, `benchmark_draws.py` and `interpret_afsr.py`: `python -m experiments.export_journal_figures` and `python -m experiments.graphical_abstract`. The Fig1 drawing is `plot_forest.build_figure` and the Fig2 drawing is `interpret.render_block_maps`; the manuscript PNGs call the same functions with their default sizes.

`experiments/attia_cnn.py` (the CNN baseline, `cnn_oof`) and `interpret.py` (the block-map export helper) are imported by the drivers above.
